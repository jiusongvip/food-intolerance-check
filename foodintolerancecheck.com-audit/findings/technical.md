# Technical SEO Findings

## 1. Sitemap Configuration Issue (Critical)

**Evidence**: The live sitemap at `https://foodintolerancecheck.com/sitemap.xml` returns only a single URL (`/lander`) — not the actual site pages. The source code `robots.txt` references `sitemap-index.xml` (generated by `@astrojs/sitemap`), but the live `robots.txt` shows `Sitemap: /sitemap.xml` (relative URL).

**Impact**: Search engines cannot discover the 23 pages on the site. This is the most critical issue found.

**Recommendation**: 
- Verify the Astro build output includes `sitemap-index.xml` with all 23 URLs
- Update the live `robots.txt` to match source: `Sitemap: https://foodintolerancecheck.com/sitemap-index.xml` (absolute URL)
- The `_redirects` file has `/sitemap.xml → /sitemap-index.xml 301` which is correct, but the live robots.txt appears to be from a different/stale deployment

## 2. robots.txt Mismatch (High)

**Source** (`public/robots.txt`):
```
User-agent: *
Allow: /
Sitemap: https://foodintolerancecheck.com/sitemap-index.xml
```

**Live** (`foodintolerancecheck.com/robots.txt`):
```
User-agent: *
Allow: /
LLM-Policy: /llms.txt
Sitemap: /sitemap.xml
```

**Impact**: The live robots.txt does not match the source code, suggesting the site was not deployed from the current codebase. The sitemap reference uses a relative URL (non-standard).

**Recommendation**: Redeploy the site to ensure source and live are in sync.

## 8. Render-Blocking Resources (Medium)
Google Fonts (`Outfit`) loaded via external stylesheet in `<head>` with `display=swap`. While `preconnect` hints are present, this still introduces a render-blocking request.

**Recommendation**: Consider self-hosting the Outfit font or using `font-display: optional` to avoid layout shifts.

## 9. No Analytics (Info)
The site explicitly does not use analytics (per privacy policy). While privacy-friendly, this means no search performance data is available. Consider adding Google Search Console verification (no tracking code needed).
